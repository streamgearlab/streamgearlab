# StreamGearLab

Free, no-nonsense tools and guides for streamers by Rig Riley at **[streamgearlab.com](https://streamgearlab.com)**.

## Open-source tools

Every tool is plain HTML, CSS and JavaScript with no build step. Use it on the site or open `index.html` locally.

| Tool | What it does | Live | Source |
| --- | --- | --- | --- |
| OBS Settings Generator | OBS bitrate, resolution, FPS, keyframe, preset and audio for Twitch, YouTube and Kick | [Use it](https://streamgearlab.com/tools/obs-settings-generator/) | [repo](https://github.com/streamgearlab/obs-settings-generator) |
| Stream Bitrate Calculator | Max safe bitrate from your upload speed, and which quality each platform allows | [Use it](https://streamgearlab.com/tools/bitrate-calculator/) | [repo](https://github.com/streamgearlab/stream-bitrate-calculator) |
| Streaming Gear Budget Builder | Category-level setup plan for a $100 to $1,000+ budget | [Use it](https://streamgearlab.com/tools/streaming-gear-budget-builder/) | [repo](https://github.com/streamgearlab/streaming-gear-budget-builder) |
| Twitch Affiliate Tracker | See which Affiliate goals you've met and get a plan for the rest | [Use it](https://streamgearlab.com/tools/twitch-affiliate-tracker/) | [repo](https://github.com/streamgearlab/twitch-affiliate-tracker) |

All tools are MIT licensed. Ideas or bug reports are welcome as issues on each repo.
